# Soil_time_series_data

Seasonal microbial substrate-induced respiration (MicroResp) and field
metatranscriptomes in the 100% irrigation treatment of the Prosser tall
wheatgrass irrigation trial (June 2023 to June 2024).

- `Scripts/`: analysis pipeline; start with `Scripts/README.md`
- `Data/`: inputs and derived tables; provenance in `Data/README.md`
- `Results/manuscript_v4/`: tables behind every figure and number
- `Figures/manuscript_v4/`: main and supplementary figures (PNG and PDF)
- `Docs/`: storyboard v4 and analysis notes (generated from the results)
- `Manuscript_analysis_plan.md`: analysis plan and decision log
