# Results

Derived tables written by the scripts in `Scripts/`. Source data stay in `Data/` and `DataHub March/`.

- `manuscript_v4/<Figure>/`: tables behind each figure. File names start with the figure and panel they support, e.g. `Figure2C_H1b_class_by_season_tests.csv`.
- `manuscript_v4/sample_availability/`: sample audit, MicroResp label check, lag pairs.
- `manuscript_v4/run_logs/`: console log of each script from the last `00_run_all.R`.
- `Data_merging_and_cleaning/`: cleaning decision log and the values affected.
