it, and an MD5 checksum, so each result can be traced to an exact file
(checksums taken 2026-10-23; check with `md5sum <file>`).

### MicroResp v3 vs the original release
- In the original file, January 2024 sample IDs SM1503–SM1514 were shifted by one plot. SM1503 was a rounded copy of SM1502, and SM1514 existed only in that file.
- v3 maps SM1502–SM1513 to the same plots as the Biogeochemistry, EEA, 16S and ITS tables. Values were relabelled, not changed: v3 SM1503 equals old SM1504.
- v3 adds Water rows for the per-mg-C normalization, with `SIR = na` (Water has no added C).
- `02_sample_availability.R` now stops if any MicroResp `Sample_cat` disagrees with the field table on plot or date.
- February 2024 plot 27 (SM1536) has no MicroResp measurement in either release.

## Transcript processing applied in this repository
`helpers.R::load_brite_c()` applies these steps in order:
1. Drop rows without a KEGG pathway code (BRITE hierarchy rows).
2. Drop pathways in the human/non-soil exclusion list.
3. Drop categories with zero expression in all 35 samples. 325 categories remain.
4. Convert each sample to proportions of its total over the 325 categories (decision D5). After filtering, per-sample totals range from 0.40 M to 1.19 M.
