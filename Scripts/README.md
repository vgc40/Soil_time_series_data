# Final manuscript scripts

Place the new final-figure R scripts here in manuscript order.

Suggested naming:

- `01_figure_1_<short_description>.R`
- `02_figure_2_<short_description>.R`
- `S01_figure_s1_<short_description>.R`

Keep each script linear and readable from top to bottom. Read source data from `Data/`, write derived tables to `Results/`, and write publication-ready plots to `Figures/`.
